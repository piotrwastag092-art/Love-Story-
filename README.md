# Ogórczak & My – Nasza Historia

Romantyczna strona o naszym związku od 14 lipca 2026.

## Jak edytować

1. Otwórz `index.html` w Notatniku lub dowolnym edytorze tekstu.
2. Zmieniaj teksty według uznania.
3. Żeby dodać zdjęcia – wrzuć je do folderu i podmień placeholdery w sekcji galerii.
